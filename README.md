# Us & Them: LLMs and Generalized Intergroup Bias

This repository contains the code, data preprocessing pipeline, and per-provider experiment runners for our final project on **predicting Interpersonal Group Relationship (IGR) and interpersonal emotion in congressional tweets using modern LLMs**.

We extend the EACL 2023 paper [*How people talk about each other: Modeling Generalized Intergroup Bias and Emotions*](https://aclanthology.org/2023.eacl-main.183/) (Govindarajan et al., 2023) by evaluating four contemporary LLMs — Claude Sonnet 4.5, GPT-4o, Gemini 2.5 Flash, and DeepSeek (chat + reasoner) — against the human and BERTweet baselines reported in the original paper. We test three prompting conditions (zero-shot, few-shot, and native extended thinking) under identical task framing, identity masking (`@Doe`), and JSON output schema.

## Code

Each LLM provider has its own directory containing a thin wrapper around a shared experiment runner:

- `claude_label/predict_igr.py` — Anthropic API
- `gpt_label/predict_igr.py` — OpenAI API
- `gemini_label/predict_igr.py` — Google Gemini API
- `deepseek_label/predict_igr.py` — DeepSeek API (OpenAI-compatible)

All cross-provider concerns — prompt templates, target masking, gold-label loading, retry/backoff logic, and CSV serialization — live in `shared/` so that prompts and preprocessing are byte-identical across runs:

- `shared/data.py` — gold standard and tweet-text loading
- `shared/prompts.py` — task framing, JSON schema, few-shot examples, `mask_handle()`
- `shared/predict.py` — generic prediction loop, retry wrapper, CSV output, CLI

`prepare_data.py` (project root) reproduces our cleaned eligibility set from the raw congressional tweet archive.

## Data

The `data/` folder contains:

- `data.tsv` — the gold standard labels from the original paper (3,033 tweets across train/dev/test splits, with IGR and 8 Plutchik emotion labels)
- `eligible_tweets.csv` — the cleaned set of 141k single-mention congressional tweets used as the source pool, generated by `prepare_data.py`

The raw tweet archive (`tweets/`) and Congress handle mappings (`twitter-handles/`) are included for reproducibility. Output predictions for each model × condition are written to the relevant `*_label/predictions_<condition>.csv`.

## Running an Experiment

```bash
# 1. Install provider SDKs (only what you need)
pip install anthropic openai google-generativeai python-dotenv

# 2. Add API keys to .env
echo "ANTHROPIC_API_KEY=sk-..."   >> .env
echo "OPENAI_API_KEY=sk-..."      >> .env
echo "GOOGLE_API_KEY=..."         >> .env
echo "DEEPSEEK_API_KEY=..."       >> .env

# 3. (Optional) regenerate eligible_tweets.csv from the raw archive
python3 prepare_data.py

# 4. Run a provider on the test split, all 3 conditions
python3 claude_label/predict_igr.py --condition all --split test

# Or one condition at a time
python3 gpt_label/predict_igr.py --condition zero-shot --split test
python3 gemini_label/predict_igr.py --condition few-shot --split test
python3 deepseek_label/predict_igr.py --condition cot-thinking --split test
```

Predictions are written to `<provider>_label/predictions_<condition>.csv` with columns:
`tweet_id, split, condition, tweeter_handle, mentioned_handle, tweet_text, predicted_igr, gold_igr, predicted_emotions, gold_emotions, model_reasoning`.
